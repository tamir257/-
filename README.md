# פלטפורמת מעקב מסחר אישית

פלטפורמת מעקב וניתוח למניות **לשימוש אישי בלבד** — לא לביצוע עסקאות (לזה יש
אפליקציית ברוקר). כולל: גרפים חיים (מושהים ~15 דק׳), כלי ניתוח טכני, תובנות
אוטומטיות והתראות, עוזר AI חכם (Claude), וחיבור read-only לתיק ב-IBKR.

## מצב נוכחי: Phase 1 (MVP) ✅

- ✅ גרף נרות אינטראקטיבי (zoom/pan) עם [lightweight-charts](https://tradingview.github.io/lightweight-charts/)
- ✅ ממוצעים נעים (SMA/EMA), Bollinger Bands, נפח מסחר
- ✅ RSI ו-MACD בפאנלים נפרדים, מסונכרנים עם הגרף הראשי
- ✅ כלי ציור: קו מגמה, קו אופקי (סרגל)
- ✅ רשימת מעקב (Watchlist) עם שמירה מקומית בדפדפן
- ✅ "ציטוט חי" מתעדכן כל 15 שניות (הנתונים עצמם מושהים ~15 דק׳ — ראה מטה)
- ✅ ממשק בעברית, RTL

## מקורות נתונים

הנתונים מגיעים מ-**Yahoo Finance** (endpoint חינמי לא-רשמי, בלי צורך במפתח
API), אך **מושהים כ-15 דקות** (ולפעמים יותר) — טרייד-אוף מודע לשלב הראשון
(ראה `src/lib/marketData/yahoo.ts`).

השכבה בנויה מאחורי ממשק גנרי (`MarketDataProvider` ב-`src/lib/marketData/types.ts`)
— כדי לעבור לספק בתשלום עם נתוני זמן-אמת אמיתיים (למשל Polygon.io / Finnhub /
Twelve Data), צריך לכתוב מחלקה חדשה שמממשת את הממשק הזה ולהחליף שורה אחת ב-
`src/lib/marketData/index.ts`. שום קוד אחר באפליקציה לא צריך להשתנות.

**היסטוריה:** בהתחלה השתמשנו ב-[Stooq](https://stooq.com), אבל כשהאפליקציה
עלתה לענן (Vercel) Stooq חסם/דחה את הבקשות שהגיעו מכתובות IP של שרתי ענן
(גם אם הן עבדו מהמחשב הביתי). `src/lib/marketData/stooq.ts` עדיין קיים
בקוד — אם תריץ את האפליקציה **מקומית** ותעדיף אותו, אפשר להחזיר אותו כברירת
המחדל ב-`index.ts`.

**הערת פיתוח:** גם עכשיו, בסביבת הפיתוח הענן שבה אני עובד יש מדיניות רשת
מוגבלת (allowlist) שחוסמת גם את Yahoo וגם את Stooq — כך שלא הצלחתי לבדוק
מכאן בפועל שהקריאות ל-Yahoo מחזירות דאטה אמיתי, כולל מ-Vercel. הקוד עבר
טייפצ'ק/לינט/בילד נקיים, אבל זו עדיין ניחוש מושכל (מבוסס על כך ש-Yahoo ידוע
כפחות תוקפני בחסימת שרתי ענן מ-Stooq) ולא אימות. **תבדוק אחרי הפריסה הבאה
ותעדכן אותי** — אם גם Yahoo נחסם, נעבור לספק עם מפתח API (כמו Twelve Data)
שלא סובל מהבעיה הזו כלל.

### פורמט טיקרים
טיקר אמריקאי רגיל (`AAPL`, `NVDA`) עובד כמו שהוא. לבורסות אחרות יש להשתמש
בסיומת של Yahoo (למשל `TEVA.TA` לתל אביב).

## למה "מקומי" ולא ענן?

זו פלטפורמה אישית עם נתונים רגישים (בעתיד — טוקן חיבור לברוקר), ולכן היא
מיועדת לרוץ **על המחשב שלך**, לא על שרת ציבורי. זה לא פוגע בטריות הנתונים —
השרת יוצא לאינטרנט כרגיל למשוך נתוני שוק, בדיוק כמו כל אפליקציה אחרת; ה"מקומי"
מתייחס רק למקום שבו השרת *רץ*.

כדי לגשת מהטלפון/מכשירים נוספים גם מחוץ לרשת הביתית, מומלץ
[Tailscale](https://tailscale.com) (VPN אישי חינמי, התקנה של כמה דקות) —
עדיף בהרבה מחשיפת הפורט לאינטרנט הציבורי.

### חלופה: אירוח בענן (Vercel), בלי IBKR

אם אין לך גישה להתקין דברים במחשב (למשל מחשב עבודה), אפשר לארח את האפליקציה
בחינם ב-[Vercel](https://vercel.com) — כניסה עם לחיצות בדפדפן בלבד, בלי
טרמינל. הדרך היחידה שזה שונה מהריצה המקומית: **חיבור ה-IBKR לא יעבוד**, כי
הוא צריך גישה ל-Gateway שרץ באותו מחשב שהדפדפן פתוח בו — ב-Vercel אין
"אותו מחשב". כל השאר (גרפים, אינדיקטורים, תובנות, התראות, צ'אט Claude)
עובד רגיל.

צעדים: מייבאים את ה-repo מ-GitHub כפרויקט חדש ב-Vercel, מוודאים ש-
**Framework Preset** מוגדר ל-**Next.js** וש-**Root Directory** ריק (אם
הפרויקט נוצר לפני שהיה קוד אמיתי ב-`main`, ההגדרות האלה עלולות להיתקע
לא-נכון — אפשר לתקן ב-Settings ← Build and Deployment ולעשות Redeploy).
מפתחות סביבה (כמו `ANTHROPIC_API_KEY`) מוגדרים ב-Settings ← Environment
Variables, ואחרי הוספה/שינוי צריך Redeploy כדי שהם ייכנסו לתוקף.

⚠️ לאפליקציה אין מסך התחברות משלה — כל מי שיש לו את קישור ה-`vercel.app`
יכול להיכנס. כל עוד אין שם IBKR מחובר זה פחות קריטי, אבל כדאי לא לפרסם
את הקישור ברבים.

  עצמו כדי לא ליצור ציפייה לא נכונה. לגמרי חינמי, לא דורש מפתח API בכלל.

### איך זה עובד (ולמה יש כאן שלב ידני)

IBKR **לא** נותנים חיבור עם שם משתמש+סיסמה ישירות מהקוד — ההתחברות (כולל
2FA) חייבת לקרות דרך דפדפן מול השרתים של IBKR עצמם. האפליקציה שלנו אף פעם
לא רואה או שומרת את הסיסמה שלך:

1. הורד את **IBKR Client Portal Gateway** (חינמי, מאתר IBKR — חפש
   "Client Portal API" ב-interactivebrokers.com או ב-IBKR Campus). דורש
   Java מותקן.
2. הרץ אותו: `bin/run.sh root/conf.yaml` (Mac/Linux) או
   `bin\run.bat root\conf.yaml` (Windows). זה מרים שרת מקומי על
   `https://localhost:5000`.
3. פתח את `https://localhost:5000` בדפדפן והתחבר עם פרטי IBKR שלך (+2FA).
   התהליך הזה קורה ישירות מול IBKR — לא דרך האפליקציה שלנו.
4. חזור לאפליקציה — פאנל "תיק IBKR" יזהה אוטומטית שההתחברות הצליחה (בודק
   כל 15 שניות) ויתחיל להציג פוזיציות.
5. האפליקציה שולחת פינג (`/tickle`) כל 50 שניות כדי למנוע ניתוק אוטומטי
   מחוסר פעילות, אבל ה-Gateway עצמו דורש התחברות מחדש בדפדפן פעם ביממה
   בערך (מדיניות אבטחה של IBKR, לא שלנו).

אם ה-Gateway רץ על כתובת/פורט אחרים, הגדר `IBKR_GATEWAY_URL` ב-`.env.local`
(ברירת מחדל: `https://localhost:5000/v1/api`).

**אזהרת אבטחה:** לאפליקציה הזו אין מערכת התחברות משלה (זו הנחת היסוד —
כלי אישי חד-משתמשי). מי שמגיע לכתובת שהאפליקציה רצה עליה יכול לראות את
הפוזיציות שלך. אם אתה משתמש ב-Tailscale (כמומלץ למעלה) זה כבר מוגבל
למכשירים שלך בלבד — פשוט אל תחשוף את הפורט לאינטרנט הפתוח.

**הערת פיתוח — הכי חשוב לקרוא כאן:** לא הייתה לי שום דרך לבדוק את השילוב
הזה בפועל — אין לי חשבון IBKR, אין לי Gateway רץ, ובסביבת הפיתוח העננית
גם לא הייתה גישת רשת לזה בכלל. הקוד כתוב לפי התיעוד הציבורי של IBKR
Client Portal Web API (מבנה ה-endpoints, שמות השדות כמו `avgCost`,
`unrealizedPnl`, `mktPrice` וכו'), אבל **לא אומת מול Gateway אמיתי**.
טייפצ'ק/לינט/בילד עברו נקי, ווידאתי שכל ה-routes מטפלים יפה במצב שבו אין
Gateway בכלל (מחזירים הודעת שגיאה ברורה במקום לקרוס). כשתריץ את זה בפועל:
- אם משהו לא מוצג נכון, לחץ על "הצג JSON גולמי" בפאנל התיק כדי לראות בדיוק
  מה חוזר מה-Gateway — זה יעזור לתקן במהירות שמות שדות אם הם שונים.
- שלח לי את הפלט ואתקן לפי מה שבאמת חוזר.
