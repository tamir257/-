# פלטפורמת מעקב מסחר אישית

פלטפורמת מעקב וניתוח למניות **לשימוש אישי בלבד** — לא לביצוע עסקאות (לזה יש
אפליקציית ברוקר). המטרה: גרפים חיים (מושהים ~15 דק׳), כלי ניתוח טכני, ובעתיד
עוזר AI חכם וחיבור read-only לתיק ב-IBKR.

## מצב נוכחי: Phase 1 (MVP) ✅

- ✅ גרף נרות אינטראקטיבי (zoom/pan) עם [lightweight-charts](https://tradingview.github.io/lightweight-charts/)
- ✅ ממוצעים נעים (SMA/EMA), Bollinger Bands, נפח מסחר
- ✅ RSI ו-MACD בפאנלים נפרדים, מסונכרנים עם הגרף הראשי
- ✅ כלי ציור: קו מגמה, קו אופקי (סרגל)
- ✅ רשימת מעקב (Watchlist) עם שמירה מקומית בדפדפן
- ✅ "ציטוט חי" מתעדכן כל 15 שניות (הנתונים עצמם מושהים ~15 דק׳ — ראה מטה)
- ✅ ממשק בעברית, RTL

## מקורות נתונים

הנתונים מגיעים מ-[Stooq](https://stooq.com) — ספק חינמי, ללא צורך במפתח API,
אך **מושהה כ-15 דקות** (ולפעמים יותר). זהו טרייד-אוף מודע לשלב הראשון (ראה
`src/lib/marketData/stooq.ts`).

השכבה בנויה מאחורי ממשק גנרי (`MarketDataProvider` ב-`src/lib/marketData/types.ts`)
— כדי לעבור לספק בתשלום עם נתוני זמן-אמת אמיתיים (למשל Polygon.io / Finnhub /
Twelve Data), צריך לכתוב מחלקה חדשה שמממשת את הממשק הזה ולהחליף שורה אחת ב-
`src/lib/marketData/index.ts`. שום קוד אחר באפליקציה לא צריך להשתנות.

**הערת פיתוח:** בסביבת הפיתוח הענן שבה נבנה הקוד יש מדיניות רשת מוגבלת
(allowlist), ו-stooq.com חסום ממנה — כך שלא הצלחתי לבדוק כאן בפועל שהקריאות
ל-API מחזירות דאטה אמיתי. הקוד עבר טייפצ'ק, לינט ובילד נקיים, אבל **כדאי
לבדוק ראשית הרצה מקומית** (`npm run dev` ואז לפתוח `/api/candles?symbol=AAPL`)
כדי לוודא שהכול עובד כשיש גישה רגילה לאינטרנט (כמו שיהיה במחשב שלך).

### פורמט טיקרים
טיקר בלי סיומת (`AAPL`) מניח בורסה אמריקאית ומוסיף `.us` אוטומטית. לבורסות
אחרות יש לציין את הסיומת של Stooq בעצמכם (למשל `teva.il`).

## הרצה מקומית

```bash
npm install
npm run dev
```
ואז לפתוח http://localhost:3000

## למה "מקומי" ולא ענן?

זו פלטפורמה אישית עם נתונים רגישים (בעתיד — טוקן חיבור לברוקר), ולכן היא
מיועדת לרוץ **על המחשב שלך**, לא על שרת ציבורי. זה לא פוגע בטריות הנתונים —
השרת יוצא לאינטרנט כרגיל למשוך נתוני שוק, בדיוק כמו כל אפליקציה אחרת; ה"מקומי"
מתייחס רק למקום שבו השרת *רץ*.

כדי לגשת מהטלפון/מכשירים נוספים גם מחוץ לרשת הביתית, מומלץ
[Tailscale](https://tailscale.com) (VPN אישי חינמי, התקנה של כמה דקות) —
עדיף בהרבה מחשיפת הפורט לאינטרנט הציבורי.

## מצב נוכחי: Phase 2א (הדרכה + התראות) ✅

- ✅ **תובנות אוטומטיות** (`src/lib/insights`) — קריאה חוקית-מבוססת של הבר
  האחרון: אזורי RSI (קניית/מכירת יתר), חציית MACD, הצלבת זהב/מוות
  (SMA20/50), נגיעה ברצועת בולינגר, נפח חריג. מוצג בפאנל "תובנות אוטומטיות"
  בסיידבר, מתעדכן אוטומטית עם כל שינוי בנתונים. זה **לא** צ'אט AI — כללים
  קבועים על אינדיקטורים ידועים, מנוסחים כתצפית ולא כהמלצה.
- ✅ **הסברים סטטיים** (`src/lib/glossary.ts`) — כפתורי "?" ליד כל אינדיקטור
  בפאנל השמאלי, עם הסבר בשפה פשוטה על מה זה ואיך קוראים אותו.
- ✅ **התראות** (`src/hooks/useAlerts.ts`) — מחיר עולה/יורד מסף מסוים (עובד על
  כל הרשימת מעקב, לא רק על הטיקר הפתוח), ו-RSI עולה/יורד מסף (פעיל רק כשהטיקר
  פתוח בגרף, כי צריך את היסטוריית הנרות לחישוב). התראה מופיעה כהודעה בתוך
  האפליקציה ובנוסף כהתראת מערכת של הדפדפן אם אישרת הרשאה. נשמר ב-localStorage.

## מצב נוכחי: Phase 2ב חלק א' (צ'אט AI עם Claude) ✅

- ✅ **עוזר AI אינטראקטיבי** (`src/app/api/chat/route.ts`, `src/components/ChatPanel.tsx`) —
  כפתור "🤖 עוזר AI" בסרגל הכלים פותח חלון צ'אט מתחת לגרף. כל שאלה נשלחת
  יחד עם תקציר קונטקסט חי (הטיקר הפתוח, המחיר, RSI נוכחי, האינדיקטורים
  הפעילים, והתובנות האוטומטיות שכבר חושבו) כך שהתשובות מבוססות על מה שבאמת
  רואים במסך ולא ניחוש. התשובה זורמת (streaming) מילה-מילה.
  התשובות מוגבלות במפורש (בהנחיה למודל) **לא** לתת המלצת קנייה/מכירה או
  ייעוץ השקעות — רק הסבר ולימוד.
- ✅ שימוש במודל `claude-opus-5` דרך ה-SDK הרשמי (`@anthropic-ai/sdk`), עם
  prompt caching על ההנחיה הקבועה כדי לחסוך עלות בשיחות ארוכות.

### הפעלת הצ'אט
1. השג מפתח API מ-https://console.anthropic.com
2. `cp .env.example .env.local` ומלא את `ANTHROPIC_API_KEY=`
3. הרץ מחדש `npm run dev`

**הערת פיתוח:** בדקתי כאן שהקוד עובר טייפצ'ק/לינט/בילד נקי, ושה-route מחזיר
הודעת שגיאה ברורה כשאין מפתח מוגדר. לא היה לי מפתח Anthropic זמין בסביבת
הפיתוח כדי לבדוק שיחה אמיתית קצה-לקצה — **כדאי לבדוק זאת ראשית** אחרי
שמגדירים את המפתח.

## מפת דרכים — Phase 2ב חלק ב' (בהמשך, דורש הרצת שירות מהצד שלך)

- 🔜 חיבור read-only ל-Interactive Brokers (Client Portal API) — פוזיציות,
  P&L והיסטוריית עסקאות, מוצג ישירות על הגרף. דורש הרצת IBKR Gateway אצלך.
  כשזה יהיה מוכן, הקונטקסט שנשלח לצ'אט יתעדכן אוטומטית לכלול גם את הפוזיציות.
- 🔜 שמירת תבניות אינדיקטורים מותאמות אישית

    Watchlist.tsx, IndicatorPanel.tsx, Toolbar.tsx
    InsightsPanel.tsx, HelpTooltip.tsx  — שכבת ההדרכה
    AlertsPanel.tsx, AlertToast.tsx     — ניהול והצגת התראות
    ChatPanel.tsx                        — חלון הצ'אט עם Claude
  hooks/
    useCandles.ts, useLiveQuote.ts     — נתוני הטיקר הפתוח
    useWatchlist.ts, useWatchlistQuotes.ts  — רשימת מעקב + ציטוטים לכולה
    useAlerts.ts                        — הגדרה/בדיקה/הפעלה של התראות
    useChat.ts                          — קריאת ה-streaming מ-/api/chat
  lib/
    marketData/             — ממשק ספק נתונים + מימוש Stooq
    indicators/              — SMA/EMA/RSI/MACD/Bollinger/VWAP (טהורים, ניתנים לבדיקה)
    insights/                — כללי "תובנות אוטומטיות" (לא AI — heuristics קבועות)
    glossary.ts              — טקסטי ההסבר לכפתורי ה-"?"
    alerts/types.ts          — טיפוסי ההתראות
    claude/                  — קליינט Claude, ההנחיה הקבועה, ובניית הקונטקסט לצ'אט
