# פלטפורמת מעקב מסחר אישית

פלטפורמת מעקב וניתוח למניות **לשימוש אישי בלבד** — לא לביצוע עסקאות (לזה יש
אפליקציית ברוקר). המטרה: גרפים חיים (מושהים ~15 דק׳), כלי ניתוח טכני, ובעתיד
עוזר AI חכם וחיבור read-only לתיק ב-IBKR.

## מצב נוכחי: Phase 1 (MVP) ✅

- ✅ גרף נרות אינטראקטיבי (zoom/pan) עם [lightweight-charts](https://tradingview.github.io/lightweight-charts/)
- ✅ ממוצעים נעים (SMA/EMA), Bollinger Bands, נפח מסחר
- ✅ RSI ו-MACD בפאנלים נפרדים, מסונכרנים עם הגרף הראשי
- ✅ כלי ציור: קו מגמה, קו אופקי (סרגל)
- ✅ רשימת מעקב (Watchlist) עם שמירה מקומית בדפדפן
- ✅ "ציטוט חי" מתעדכן כל 15 שניות (הנתונים עצמם מושהים ~15 דק׳ — ראה מטה)
- ✅ ממשק בעברית, RTL

## מקורות נתונים

הנתונים מגיעים מ-[Stooq](https://stooq.com) — ספק חינמי, ללא צורך במפתח API,
אך **מושהה כ-15 דקות** (ולפעמים יותר). זהו טרייד-אוף מודע לשלב הראשון (ראה
`src/lib/marketData/stooq.ts`).

השכבה בנויה מאחורי ממשק גנרי (`MarketDataProvider` ב-`src/lib/marketData/types.ts`)
— כדי לעבור לספק בתשלום עם נתוני זמן-אמת אמיתיים (למשל Polygon.io / Finnhub /
Twelve Data), צריך לכתוב מחלקה חדשה שמממשת את הממשק הזה ולהחליף שורה אחת ב-
`src/lib/marketData/index.ts`. שום קוד אחר באפליקציה לא צריך להשתנות.

**הערת פיתוח:** בסביבת הפיתוח הענן שבה נבנה הקוד יש מדיניות רשת מוגבלת
(allowlist), ו-stooq.com חסום ממנה — כך שלא הצלחתי לבדוק כאן בפועל שהקריאות
ל-API מחזירות דאטה אמיתי. הקוד עבר טייפצ'ק, לינט ובילד נקיים, אבל **כדאי
לבדוק ראשית הרצה מקומית** (`npm run dev` ואז לפתוח `/api/candles?symbol=AAPL`)
כדי לוודא שהכול עובד כשיש גישה רגילה לאינטרנט (כמו שיהיה במחשב שלך).

### פורמט טיקרים
טיקר בלי סיומת (`AAPL`) מניח בורסה אמריקאית ומוסיף `.us` אוטומטית. לבורסות
אחרות יש לציין את הסיומת של Stooq בעצמכם (למשל `teva.il`).

## הרצה מקומית

```bash
npm install

```
ואז לפתוח http://localhost:3000

## למה "מקומי" ולא ענן?

זו פלטפורמה אישית עם נתונים רגישים (בעתיד — טוקן חיבור לברוקר), ולכן היא
מיועדת לרוץ **על המחשב שלך**, לא על שרת ציבורי. זה לא פוגע בטריות הנתונים —
השרת יוצא לאינטרנט כרגיל למשוך נתוני שוק, בדיוק כמו כל אפליקציה אחרת; ה"מקומי"
מתייחס רק למקום שבו השרת *רץ*.

כדי לגשת מהטלפון/מכשירים נוספים גם מחוץ לרשת הביתית, מומלץ
[Tailscale](https://tailscale.com) (VPN אישי חינמי, התקנה של כמה דקות) —
עדיף בהרבה מחשיפת הפורט לאינטרנט הציבורי.

## מבנה הקוד

```
src/
  app/
    api/candles/route.ts   — proxy שרת-צד ל-Stooq (נרות היסטוריים)
    api/quote/route.ts     — proxy שרת-צד ל-Stooq (ציטוט אחרון)
    page.tsx               — הדף הראשי, מחבר את כל הרכיבים
  components/
    PriceChart.tsx          — גרף נרות ראשי + אוברליים + כלי ציור
    IndicatorSubChart.tsx   — פאנל משני מסונכרן (RSI/MACD)
    Watchlist.tsx, IndicatorPanel.tsx, Toolbar.tsx
  hooks/
    useCandles.ts, useLiveQuote.ts
  lib/
    marketData/             — ממשק ספק נתונים + מימוש Stooq
    indicators/              — SMA/EMA/RSI/MACD/Bollinger/VWAP (טהורים, ניתנים לבדיקה)
```
